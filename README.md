# Ghost Dice — Privacy Policy Website 🎲👻

A clean, modern, and responsive privacy policy website for **Ghost Dice**.

Built with semantic HTML5, modern Vanilla CSS, and lightweight JavaScript.

---

## ✨ Features

- **Accurate to the Ghost Dice Architecture**: Covers the 100% offline nature, local SQLite and SharedPreferences storage, zero data tracking, zero ads, zero permissions, and COPPA compliance.
- **Support Contact Integrated**: Highlights `support.ghostdice@gmail.com` with one-click clipboard copying and direct `mailto:` links.
- **Theme Support**: Seamless Dark and Light theme toggle with automatic persistence and OS preference detection.
- **Reading Progress Bar**: Dynamic top progress bar indicating reading depth.
- **Interactive Table of Contents**: Sticky sidebar navigation with smooth scroll-spy highlighting active sections.
- **Mobile Responsive**: Perfectly optimized for desktop, tablet, and mobile browsers.

## 🚀 How to Host / Publish

### Option 1: Static Web Hosting (Vercel, Netlify, Cloudflare Pages, etc.)
Simply drag & drop or connect this directory to any static hosting provider.

### Option 2: GitHub Pages (Optional)
1. Push this directory to a repository.
2. Go to repository **Settings** > **Pages**.
3. Under **Branch**, select `main` (root `/`) and click **Save**.
4. You can paste the resulting live URL into your Google Play Console or App Store store listing.

### Option 3: Local Preview
Run any local static server:
```bash
# Python
python -m http.server 8080

# Or npx serve
npx serve .
```
Then open `http://localhost:8080` in your web browser.
